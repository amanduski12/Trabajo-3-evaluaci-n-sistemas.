# Software Instalado en Windows 11

Este documento recoge el software instalado en los equipos de la empresa y su finalidad dentro del entorno profesional.

---

## 1. Navegador Web

### ✔ Google Chrome
- Navegador principal para los empleados.
- Compatible con aplicaciones web empresariales.
- Rápido y seguro.

---

## 2. Suite Ofimática

### ✔ Microsoft Office / LibreOffice
Incluye:
- Procesador de textos
- Hojas de cálculo
- Presentaciones

Uso:
- Documentación interna
- Informes
- Gestión administrativa

---

## 3. Herramientas de Utilidad

### ✔ 7-Zip
- Compresión y descompresión de archivos.
- Compatible con ZIP, RAR, 7z y más.

### ✔ Adobe Acrobat Reader
- Lectura de documentos PDF.
- Imprescindible para facturas, informes y manuales.
